2. Like and Comment Box

Building like and comment box by using DOM manipulation.

You can like the post and add comments interactively. At the moment, any likes or comments you make will disappear if you refresh or reload the page because they are not saved yet.

The current likes and comments are manually added as placeholder data. I'll update this feature once I learn and implement Local Storage or connect it to a database, so your interactions will be saved permanently. Stay tuned for future updates!
