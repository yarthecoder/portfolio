6. Search Box

Building a simple search box using JavaScript arrays and DOM manipulation.

This project allows users to search for a fruit by name. When a match is found, the page automatically scrolls to the corresponding HTML section. If no match is found, an error message is displayed inside the input field and automatically selected, allowing the user to immediately type another search without manually clearing the text.

What I learned from this Project

  • Reading user input with .value
  • Cleaning user input using .trim() and .toLowerCase()
  • Using a guard clause to prevent empty searches
  • Storing searchable data in a JavaScript array
  • Selecting HTML elements dynamically with document.getElementById()
  • Improving user experience by selecting the error message with .select() so users can immediately type a new search

This project taught me to think like a developer instead of copying code. Rather than memorizing methods, I learned to break the problem into smaller steps:

  1. Read the user's input.
  2. Validate the input.
  3. Search the data.
  4. Find the matching HTML element.
  5. Navigate to the correct section.
  6. Handle the case when no result is found.
Learning through questions and problem-solving helped me understand why each method is used, not just how to write it.
