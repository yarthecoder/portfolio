I clearly understand from this project that global state is convenient when a project is small, but as the system becomes more complex, references become much more powerful and reliable.

This was also my first real experience understanding the importance of data architecture and data arrangement.

I learned that building a good application is not only about how the UI looks or whether the code works. It is also about how information is organized, how components relate to each other, and how state and references flow through the system.

This project was my first real touch with that idea, and it changed the way I think about JavaScript development.
