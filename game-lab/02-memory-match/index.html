What I learned from this Project

This is my 2nd game built with the DOM. I brought some of the concepts I learned from Processing.js lessons on Khan Academy into this project, and I was honestly surprised by how clean and simple the implementation became with the DOM.

One thing I especially enjoyed was using buttons as the tiles and letting CSS control their visual states instead of creating two actual faces and managing the flip entirely with JavaScript.

Through this project, I learned more about separating data from the DOM, managing game state, working with arrays, creating reusable functions, handling events, and thinking about the flow of a game rather than just making individual features work.

I'm starting to realize that good code isn't only about making something work — it's also about making the logic easy to understand and extend.

Coding is fun. 🚀 Stay tuned for V2.
