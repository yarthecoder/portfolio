What I learned from this Project

Every time when I create something, I focus on scalable and cleaner code.

In this game, I built it with separate helper functions such as "updateUI()" to update the UI for each state, and "checkWinner()" and "checkDraw()" for the game logic. I also got a new way of thinking about the logic with "winningPatterns".

That's why my click listener is so clean and pretty. I don't need to put too much effort into my thinking every time when I review the game.

This is what I like about separating functions, but if you do too much separation, the code can become messy too. So, be careful.
