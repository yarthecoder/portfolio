What I learned from this Project

  • Built a multi-theme system using CSS variables (:root).
  • Learned how to organize colors with design tokens such as --bg-color, --surface-color, --text-color, and --accent-color.
  • Understood the difference between background, surface, and accent colors when designing a user interface.
  • Learned how to structure a webpage using reusable layout components like containers, cards, header, main, and footer.
  • Discovered how CSS variables make code clean, maintainable, customizable, and scalable.
  • Learned how the spread operator (...) can pass every item in an array to classList.remove().
  • Discovered how the modulo operator (%) creates an infinite loop through the theme array without writing additional reset logic.
  • Improved my understanding of how HTML, CSS, and JavaScript work together:

This project completely changed the way I think about CSS and HTML structure. Before learning CSS variables, changing a website's appearance meant editing many different CSS rules. Now I understand how a small set of reusable variables can control the entire design, making future changes much faster and easier. More importantly, this project taught me that writing scalable code is not about writing less code—it's about organizing code so it is easy to understand, maintain, and extend as a project grows.
