What I learned from this Project

This project started with a simple idea: building a Dark Mode by using classList.toggle(). However, while building it, I kept getting new ideas, and it gradually grew into a small interactive webpage instead of just a single button.

The more I built, the more problems I faced, and every problem taught me something new. One of my favorite discoveries was CSS Nesting. Before finding it, I was writing many repetitive CSS selectors and JavaScript lines just to change the theme. After learning CSS Nesting, my CSS became much cleaner, my JavaScript became much shorter, and the entire project was much easier to maintain. For example, my first approach looked something like this:

Before (Many JavaScript lines)

header.classList.toggle("dark");
logo.classList.toggle("dark");
nav.classList.toggle("dark");
button.classList.toggle("dark");
footer.classList.toggle("dark");

After reorganizing my CSS with nesting, I only needed to change one parent element:

After (Cleaner JavaScript)

demoCanvas.classList.toggle("dark");

Then CSS takes care of everything:

#demoCanvas.dark {

#demoHeader { background: #333; }
a { color: white; }
button:hover { color: gold; }

}

I think this was one of the coolest moments in my learning journey. Instead of making the code simply work, I learned how to make it cleaner, easier to read, and easier to maintain.
